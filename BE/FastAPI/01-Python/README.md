# Python: from scratch to advanced

Read in order. Type every example into a file and run it with `python file.py`, or experiment in the interactive shell (`python` or `python -i file.py`).

| # | Lesson | Level | You will learn |
| --- | --- | --- | --- |
| 00 | [How Python works internally](00-how-python-works.md) | Overview | Bytecode and the CPython VM, objects and references, memory management, attribute lookup, imports, the GIL, the event loop |
| 01 | [Setup and basics](01-setup-and-basics.md) | Beginner | Installing Python, running code, variables, types, operators, strings, input/output, if/else, loops |
| 02 | [Data structures](02-data-structures.md) | Beginner | Lists, tuples, dicts, sets, comprehensions, slicing, copying, sorting |
| 03 | [Functions](03-functions.md) | Beginner → Intermediate | Parameters, `*args`/`**kwargs`, scope, lambdas, closures, recursion, built-in functions |
| 04 | [Object-oriented programming](04-oop.md) | Intermediate | Classes, methods, inheritance, properties, dunder methods, dataclasses, abstract classes |
| 05 | [Modules, packages and environments](05-modules-packages-environments.md) | Intermediate | Imports, packages, `__name__`, virtual environments, pip, uv, `pyproject.toml` |
| 06 | [Errors, files and the standard library](06-errors-files-stdlib.md) | Intermediate | Exceptions, custom errors, files, `pathlib`, JSON, CSV, datetime, logging, collections |
| 07 | [Advanced Python](07-advanced.md) | Advanced | Iterators, generators, decorators, context managers, `functools`, `itertools`, the data model |
| 08 | [Type hints](08-type-hints.md) | Advanced | Annotations, generics, `Protocol`, `TypedDict`, mypy/pyright, Pydantic basics |
| 09 | [Concurrency and async](09-concurrency-async.md) | Advanced | Threads, processes, the GIL, `asyncio`, `async`/`await`, tasks, `httpx` |
| 10 | [Testing with pytest](10-testing-pytest.md) | Advanced | Tests, fixtures, parametrize, mocking, coverage |
| — | [**Production**](production.md) | — | Python versions, dependency locking, configuration, logging, performance, security in production |

**Python version:** examples assume **Python 3.12+**.
