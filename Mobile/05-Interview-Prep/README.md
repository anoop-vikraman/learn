# Mobile interview prep

| File | Use |
| --- | --- |
| [01-interview-questions.md](01-interview-questions.md) | ~60 questions with model answers: internals, components, navigation, performance, native, builds, OTA, scenarios |
| [02-cheat-sheet.md](02-cheat-sheet.md) | Fast revision: APIs, props, commands, gotchas, and the numbers worth quoting |
| [03-talking-about-your-work.md](03-talking-about-your-work.md) | How to present mobile experience: STAR stories, system-design answers, and what to say if you've never shipped to a store |

## How to use this folder

1. **Two weeks out:** read the questions file with answers hidden, say each answer out loud, mark the ones you fumbled.
2. **One week out:** re-read `../01-Fundamentals/00-how-react-native-works.md` and `../04-Build-Deploy/03-ota-updates.md` — the two topics interviewers use to separate levels.
3. **The night before:** the cheat sheet only.
4. **Always:** have one real app you can talk about in detail, including something that went wrong.
