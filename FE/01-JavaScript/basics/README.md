# JavaScript basics: start here

These lessons take you from zero to writing real JavaScript. Read them **in order**: each one builds on the previous one. Type out every example yourself in the browser console (F12 → Console) or in a file run with Node (`node file.js`).

| # | Lesson | You will learn |
| --- | --- | --- |
| 01 | [Getting started, variables and types](01-getting-started-variables-types.md) | How to run JS, `let`/`const`, the 8 data types, `typeof`, type conversion, truthy/falsy |
| 02 | [Operators and control flow](02-operators-control-flow.md) | Arithmetic, comparison (`==` vs `===`), logical operators, `??`, `?.`, if/else, switch, loops |
| 03 | [Functions and scope](03-functions-scope.md) | Declarations, arrow functions, parameters, return, scope, hoisting, closures, `this` |
| 04 | [Arrays](04-arrays.md) | Creating, reading, adding/removing, `map`/`filter`/`reduce`/`find`, sorting, spread, destructuring |
| 05 | [Objects and classes](05-objects-classes.md) | Objects, properties, methods, destructuring, spread, copying, JSON, classes, prototypes |
| 06 | [Strings, numbers, dates, Map and Set](06-strings-numbers-dates.md) | String methods, template literals, number gotchas, `Math`, `Date`, `Map`, `Set` |
| 07 | [Asynchronous JavaScript](07-async-promises-fetch.md) | Callbacks, timers, promises, `async`/`await`, `fetch`, error handling, the event loop |
| 08 | [DOM, events, modules and errors](08-dom-events-modules-errors.md) | Selecting and changing elements, events, forms, `import`/`export`, `try`/`catch`, storage |
| — | [**Cheat sheet**](cheat-sheet.md) | Every common built-in function: arguments, return values, edge cases and things people forget |

When you finish these, continue with the interview-level notes in the parent folder ([../](../)).

## How to practise

1. After each lesson, close it and rewrite the examples from memory.
2. Do the small exercises at the end of each lesson.
3. Keep the [cheat sheet](cheat-sheet.md) open while coding until you no longer need it.
