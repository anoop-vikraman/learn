## How to use these

1. **Replace every `[bracket]`** with your real detail: numbers, names, what *you* did. Model answers only help if they match what actually happened. An interviewer who digs one level deeper will notice an invented answer.
2. Answers are hidden in `<details>` blocks. Open the Markdown preview (Ctrl+Shift+V), read the question, answer **out loud**, then click to compare.
3. For each CV bullet, be ready for three levels of questions:
   - **What** did you build?
   - **How** does it work? (draw it, or write the code)
   - **Why** this way, and what would you change now?
4. Every bullet you can't defend at level 3 should be reworded or dropped before you send the CV out.
